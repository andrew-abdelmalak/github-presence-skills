# Security policy

## Supported versions

Only the latest release receives security fixes.

## Report a vulnerability

Do not report security problems in public issues, discussions, or pull requests.

Report them privately through [GitHub private vulnerability reporting](https://github.com/andrew-abdelmalak/github-presence-skills/security/advisories/new).

Relevant problems for this package include:

- A skill instruction or bundled script that runs a remote or destructive command without the user's approval
- A way for text in someone else's repository (a README, issue, or pull request) to make a skill act on it as instructions
- A script that could leak tokens, secrets, or private data

Include the skill name, the prompt or repository content that triggers the problem, and what happened.

## What happens next

You will get a reply as soon as the maintainer can review the report. Once a fix is released, you will be credited in the advisory unless you prefer otherwise.
